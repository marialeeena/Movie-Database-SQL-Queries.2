# Movie Database SQL Queries (Exercise 2)

A collection of complex SQL queries implemented and executed on a relational movie database as part of the Database Design course.

## Overview

This script contains solutions for 10 distinct analytical queries involving multi-table joins, aggregations, subqueries, set operations, and relational division logic without relying on flow control operators.

## Key Features & Query Implementations

- **Multi-Table Joins & Filtering:** Queries designed to track specific actor participations (e.g., surname "Allen") across genres like Comedy.
- **Advanced Aggregations:** Utilizing `GROUP BY` and `HAVING` clauses to filter directors based on diverse genre direction counts and actors based on exact film appearances.
- **Set Operations:** Implementing set intersections and unions (such as checking criteria across matching actor/director surnames and verifying conditional existence like 1995 Drama movies).
- **Complex Correlated Subqueries & Relational Division:** Solving advanced requirements such as finding actors who have starred in movies across all genres or evaluating exclusive director-genre relationships.
